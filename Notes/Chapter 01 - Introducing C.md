# **1.2 Strengths and Weaknesses of C**

## Learning Notes (Temporary)
- **C is:**
	- **a low level language**: C provides access to machine level concepts such as bytes and addresses. its operations also correspond closely with the computers built in instructions, allowing programs to be fast.
	- **a small language:** Provides a limited set of features, instead choosing to rely on libraries 
	- **a permissive language**: allows a wider degree of attitude 
	  
- **Strengths**:
	- **Efficiency** - Programs run quickly in Limited amounts of energy 
	- **Portability** - allowing it to run on different types of computers with much less effort than Assembly code. 
	- **Power**- Utilise a large collection of data types and operators making a powerful language
	- **Standard libraries** - containing numerous functions 
	- **integration with UNIX** - C combine Unix effectively
	- **Flexibility** - Very few restrictions allows C to be used in multiple applications, making programming easier
- **Drawback** - most of C drawbacks comes as a result of its strengths 
	- **Error-prone programs** - C's high flexibility may let bugs slip through
	- **Programs can be difficult to understand** - Numerous unique features
	- **Difficult to modify** -  Large programs in C are hard to change, especially since C lacks features like classes and packages.
	  
- **How to effectively use C**
	- **Utilising software tools** -> tools like lint, subject a program to more extensive error analysis than most C compilers. making programs more reliable
	- **Take advantage of libraries** -> error free and saves time
	- **Using sensible coding conventions** ->a CC is a style that a programmer adopts. This makes programs easier to read and modify .
	- **Stick to the standard** -> C compilers provide features that aren't part of C89 or C90. to maintain portability avoid un-standard features and libraries
